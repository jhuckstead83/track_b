The paper and the live game

The supplied 13-page paper is retained exactly. It uses the game’s first name, “Rotor 51”, for the original isolated-point prototype. The game is now Prospect 51 everywhere on the site and uses the shared jbit bank. Saved-hand keys keep their original id, so no unfinished hand is lost to the rename. The identity dictionary, rotor sampling, poker awards, draw rules, and initial-order jackpot condition are unchanged.

What the mathematics establishes

The five opening rotors select without replacement, with moduli 51, 50, 49, 48, and 47. Coprime affine gearing permutes the eligible positions. Under independent uniform input digits, every ordered hand has probability 1 / 281,887,200.

After the opening deal, all five initial identities stay out of the replacement pool, including discarded cards. Replacing r cards has C(46, r) possible unordered completions. The opening census contains 2,349,060 hands; its counts are not an optimal-play return calculation.

Poker forgets order; the archive lock retains it. Swapping two cards can preserve the poker award and destroy the jackpot match. The archive match is fixed by the opening deal and survives a later redraw.

Why 51, by deduction

Formula 51 builds the 51 identities from the Hangul syllable block with radix N = 1438, and any radix from 1177 to 1764 also gives 51 symbols. A sharper statement holds. Call a radix self-describing when its number of symbols equals its number of complete syllable contexts. Then 51 is the only possible count, reached exactly for N = 1428–1455. Among those, 1437–1440 score best on Project 51’s decoders, and only 1438 has two nine-member partial classes. So the data-given radix is picked out exactly. Proved, with an exhaustive check over all 11,172 radices. One step of the first proof was repaired on 27 September; an independent recomputation reproduces all 588 band tables.

A more legible table does exist: at N = 1353–1356, class, polar address and color identify every card. It gives up self-description, so it is a design choice, not a correction. Read the deduction · script · all 11,172 radices · independent replay
