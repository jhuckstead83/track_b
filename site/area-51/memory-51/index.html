MEMORY 51 / LIVE RULE CARD · v2.0

A card and its other name.

The default key is the exact 51-component alphabet from Invariant. The marker Ⅰ = 2♣ is outside it. Card → stamp and symbol → card test the same bijection in opposite directions.

Each question offers four distinct choices. A correct answer without using Study earns 2 jbits, up to 8 per UTC day. Opening the page, waiting, skipping, or revealing the answer earns nothing. Incorrect and assisted answers remain useful practice and are recorded separately.

The four-choice reference has a two-bit fixed-width answer budget. The +2 jbit award is a chosen price, not an estimate of knowledge gained. Correctness, direction, response time and assisted status remain separate in your receipt.
